# Licenses and redistribution boundaries

Linux kernel COPYING and LICENSES/ are preserved in kernel/. The kernel is GPL-2.0-only with the documented syscall exception; individual files may use compatible dual licenses. Preserve per-file SPDX identifiers and copyright notices.

The root LICENSE files of KernelSU Next, SUSFS, NoMount and DroidSpaces contain GPL version 3 text. KernelSU Next additionally has an explicit kernel/LICENSE containing GPL version 2; that kernel-specific license and the GPL-2.0 / GPL-2.0-only file notices are preserved. DroidSpaces is separate userspace software, and its prerequisite configuration does not itself link its application into Linux. The unresolved integrated-code question chiefly concerns SUSFS and NoMount: only their GPLv3 root licenses were found, with no separate kernel license found at the pinned revisions. MODULE_LICENSE("GPL") alone does not resolve version compatibility. This export preserves the source licenses verbatim and **does not claim that every integrated source file is licensed compatibly for distribution as a combined GPL-2.0-only kernel binary**. A maintainer must review the kernel portions and obtain clarification/permission where necessary before public distribution. No combined binary is included in the public archive. Source aggregation here is a review artifact, not a legal clearance or relicensing.

OEM source references are provided with exact commits; local OEM snapshots retain their notices. Proprietary/precompiled FPSGO/MSYNC objects and firmware, ramdisk, DTB, AVB and Android images are not publicly redistributed here. Their local availability does not establish publication rights. Obtain them from an authorized source under applicable terms. FPSGO patches retain original copyright context; apply them only to the exact documented OEM source.

Opaque bundled utilities, APK/JAR/assets, toolchain binaries and upstream private test-key files are excluded from the public export; see manifests/export-exclusions.json. Corresponding source obligations and full notices must be reviewed before adding any binary release. Attribution in third-party code and MAINTAINERS is intentionally preserved; it identifies public upstream authors, not the owner's private Git identity.

New archival documentation and scripts are supplied for this source review under GPL-2.0-or-later. This does not change any third-party file's license. Nothing and Android names identify compatibility and do not imply endorsement.

The public kernel licensing rules state GPL version 2 only: https://docs.kernel.org/process/license-rules.html . GNU explains that GPLv3 is not compatible with GPLv2 by itself: https://www.gnu.org/licenses/license-list.en.html#GPLv3 . These primary references support the need for review; they do not determine the applicable grant for every file in these particular component trees. The uncertainty affects publication of the integrated source snapshot as well as a combined binary. **Public release of this review archive is pending that clarification.**
